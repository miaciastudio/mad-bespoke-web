# 👑 Mad Bespoke — Digital Storefront

Handcrafted luxury personalized gifts, laser-engraved pens, leather gift sets, stainless steel kadas, and custom accessories digital storefront.

## 🚀 Stack
- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS + Custom Warm Beige / Burgundy / Gold Design System
- **Icons:** Lucide React + Custom SVG Brand Icons
- **Hosting / Edge:** Cloudflare Pages
- **Database & Media:** Turso LibSQL + Cloudflare R2
- **Ordering:** Dynamic 1-Click WhatsApp Concierge Engine

## 🎨 Design System
- Canvas Background: `#E8DDD3` / `#F4ECE4` (Warm Beige)
- Cards: `#FAF7F4` (Cream)
- Primary Accents: `#722F37` (Deep Burgundy)
- Accents & Badges: `#B8944F` (Muted Gold)
- Typography: `Playfair Display` + `Plus Jakarta Sans`

## 🛠️ Deployment on Cloudflare Pages
- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node.js version:** `20+` or `22+`
